# Cucumber for Rust

Build native Rust acceptance tests with reusable Gherkin features, source-preserving reports and explicit compatibility policies.

This is the **GQAdonis fork** of cucumber-rs/cucumber. This documentation is **not endorsed** by the upstream Cucumber projects. The verified foundation is preserved through phase45; full Cucumber.js parity is not claimed.

Use the [getting-started guide](./getting-started.md) for a pinned checkout, then choose the policies your application needs. The [compatibility matrix](./compatibility.md) separates supported behavior from remaining boundaries. [Evidence](./evidence.md) links the retained phase-end BDD results.

The foundation provides native Gherkin compilation, standard Messages NDJSON, ordered lifecycle callbacks, typed attachments, deterministic scheduling and source-based rerun selection. [VLBV integration](./vlbv.md) projects explicitly bound receipts without changing canonical phase or release state.

The [SDK roadmap](./sdk.md) covers the requested extensible Rust surface and TypeScript/Python native bindings. Those additions remain proposed, not available packages.

This additive Docusaurus site keeps the existing Rust book and build/release workflows intact. Hosting is undecided; no site deployment is claimed. See the [preserved delivery record](https://github.com/GQAdonis/cucumber/blob/82c86632d63b323d4c3abdce24c404d0029158d0/docs/compatibility/DELIVERY.md).
