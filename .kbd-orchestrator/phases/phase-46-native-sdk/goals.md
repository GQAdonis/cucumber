# Phase46 proposed value: native source and evidence SDK

A Rust, TypeScript or Python application can compile source-faithful Gherkin43
AST/Pickles and derive a lossless Messages rerun plan through the same existing
Rust implementation, using in-process native bindings installed from local
package artifacts. A Rust application can extend the SDK through a safe explicit
extension interface. This first phase is an interoperable toolkit, not yet foreign
step execution or a Behave/pytest adapter. The full requested programme continues
through runtime bindings, documentation sites, review and contribution.

Status: PROPOSED; owner calibration/adoption pending. No SDK/binding production or
executable tests have been generated. Prior phases1-45 are historical evidence.
BDD-only; no generated-code execution until complete adopted phase end.
